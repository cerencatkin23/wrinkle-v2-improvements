Key implementation details
1) Dataset handling
- Roboflow-compatible loader in src/wrinkle_v2/data/roboflow_dataset.py.
- Auto-detects YOLOv8-seg polygons (.txt) and COCO JSON segmentation.
- Rasterizes polygons to a binary wrinkle mask.
- Uses consistent resize with padding and nearest-neighbor for masks.
- Augmentations (mild brightness/contrast, blur/noise, flip) in augmentations.py.

2) Segmentation model
- UNet with ResNet34 encoder (torchvision), in src/wrinkle_v2/models/unet.py.
- Loss: Dice + BCE.
- Metrics: Dice, IoU.
- Training script: scripts/train_seg.py
  - Added auto-resume from checkpoints/wrinkle_unet_last.pt.
  - Saves best to checkpoints/wrinkle_unet_best.pt and TorchScript to checkpoints/wrinkle_unet_best.ts.
  - Saves last checkpoint each epoch.

3) Quality gate
- Implemented in src/wrinkle_v2/quality/quality_gate.py.
- Checks: blur (Laplacian variance), brightness, face size, pose (yaw/pitch/roll), missing landmarks.
- Uses MediaPipe FaceMesh when available; falls back to Haar face detector.
- Added allow_haar_fallback flag in config:
  - configs/default.yaml: allow_haar_fallback: false
  - configs/local.yaml: allow_haar_fallback: true
- Haar fallback can pass quality if face is detected and other checks pass, even without landmarks.

4) Region mapping + measurements
- MediaPipe landmarks define regions: forehead, glabella, bunny_lines, crow’s feet L/R, under-eye L/R,
  nasolabial L/R, smoker_lines, chin.
- Measurements computed per region and globally:
  - area_ratio, coverage_pct, skeleton_length, thickness, density.
- Added Haar-based approximate region masks if landmarks are unavailable (rect/ellipse approximations).

5) Measurement-based scoring and reasoning
- Scoring in src/wrinkle_v2/scoring.py.
- No confidence-based scoring; derived from mask geometry metrics.
- Uses normalization ranges and weights from configs/default.yaml.
- Deterministic reasoning string based on thresholds and metrics.

6) Inference and API
- CLI: scripts/predict.py (optional overlay output).
- FastAPI server: scripts/server.py.
- Inference uses inference.mask_threshold from config.

7) Smoke test
- scripts/smoke_test.py loads one test image, runs pipeline, and validates JSON schema keys.
- Disables MediaPipe during smoke test to avoid native crashes.

8) Evaluation and calibration
- scripts/eval_seg.py computes Dice/IoU on valid and test, writes runs/metrics.json.
- scripts/calibrate_threshold.py sweeps binarization threshold to maximize Dice on valid,
  writes runs/threshold_sweep.json.
